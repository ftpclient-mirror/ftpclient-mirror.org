# FTPClient Mirror

Mirror providing FileZilla client downloads.

**Website:** [ftpclient-mirror.org](https://ftpclient-mirror.org)

## Verification

Each file has a SHA256 checksum alongside it.

Official SHA512 checksums file is also provided.

## API

Version information: `https://cdn.ftpclient-mirror.org/latest.json`
